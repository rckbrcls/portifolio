## Why native and local-first

Sparky is a native macOS app in Swift and SwiftUI. Calendar, Mind, Focus, and Me
live in a desktop-specific shell instead of a web app wrapped in a window. That
choice was about feeling like a Mac tool: navigation, notifications, and local
files that belong on the machine.

SwiftData stores Memories, Minds, schedules, checklists, and completion history.
Photos, links, audio, and files sit separately in Application Support, with
references held by the main data model. Persistence and product services stay
inside the app. There is no custom API server, account system, cloud-sync
service, analytics integration, or advertising layer.

## Focus, notifications, and shipping updates

The Focus engine supports configurable work, short-break, long-break, cycle,
pause, reset, and extension behavior. UserNotifications covers scheduled
reminders and focus-session feedback on macOS.

Shipping the app was part of the product too. GitHub Actions builds universal
release archives, GitHub Releases distributes them, and Sparkle checks for
updates through a published appcast. A public installer selects the latest
compatible release for a one-line install.

I designed and built Sparky as a personal tool: the desktop experience, the
local data architecture, the memory and organization workflows, Focus, release
automation, the installer, and the update channel.
