## A native SwiftUI application

Swift and SwiftUI provide the main application and interface, with AppKit supporting window and menu bar behavior.

UserDefaults stores local preferences, focus-session state, and history. Swift Charts visualizes recent patterns, UserNotifications supplies session feedback, and Sparkle provides the update architecture.

The implementation favors native macOS surfaces and local persistence instead of a wrapped web application or custom backend.

Local persistence keeps the product simple and private, but it does not provide cross-device synchronization or the querying guarantees of a dedicated database.

I designed and built the application, focus-session behavior, preferences, local history, statistics, notifications, release automation, and original product website.
