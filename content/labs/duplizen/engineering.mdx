## Realtime rooms coordinated near the database

Duplizen is a Next.js, React, and TypeScript app with Supabase and PostgreSQL
behind it. Rooms, players, roles, rounds, votes, and game state live in the
database. Realtime subscriptions push the relevant changes to whoever is
connected.

I put a lot of the coordination next to the data. Database functions own shared
transitions, and row-level security narrows which records a participant can
touch. That keeps multiplayer rules closer to one source of truth, but it also
makes consistency and reconnection harder than a single-device game.

I designed and implemented the product, the application flows, the multiplayer
data model, the policies, and the controlled game-state transitions. I also used
the project as a practical way to study Supabase Realtime, room state, and
multiplayer consistency without turning the game night into a distributed
systems lecture.
